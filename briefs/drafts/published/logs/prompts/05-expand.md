# Prompt 05: Expand

Turn one line into a full content brief.

## Input
A one-liner hook or idea, plus a target pillar.

## Output
A brief file at briefs/[slug].md with:
- Pillar tag
- Platform
- Format
- Hook
- Promise
- Body direction (3 bullet points max)
- CTA
- Suggested visual direction (one line)
- Status: brief

## Rules
- Do NOT write the full draft. Write the brief only.
- Each bullet point is one line with a real example
- Keep it South African and specific
- Make the hook feel like something Gareth or Brian
  would stop scrolling for

## After
Hand off to prompts/01-draft.md to turn into full content.
