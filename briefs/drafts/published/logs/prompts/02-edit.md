# Prompt 02: Edit

Act as a ruthless editor, not the author.

## Input
A file at drafts/[SLUG].md with status: draft.

## Output
Rewrite the draft in place. Keep the promise. Cut the fat.

Pass 1 — Structure
- Does the hook stop the scroll in the first line?
- Does every line earn its place?
- Is the CTA a benefit not a command?

Pass 2 — Voice
- Strip filler words
- Shorten any sentence over 15 words
- Replace generic with specific and South African
- Check every line against CLAUDE.md voice rules

Pass 3 — Truth
- Does this feel like it came from a real person?
- Would Gareth share this with his mates?
- Would Brian save this on his phone?

## Output contract
- Rewrite the file in place
- Set status: edited
- Log changes made
- Leave 2 to 3 questions for the human at the bottom
  under "Questions for you" — real ambiguities only
