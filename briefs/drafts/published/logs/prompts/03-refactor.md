# Prompt 03: Refactor

Repackage one piece of content into channel-native versions.
Same idea. Fresh hook. Native format per channel.

## Input
An edited file at drafts/[SLUG].md with status: edited.

## Output
Create one new file per channel under drafts/[SLUG]/:

- instagram-caption.md
  Hook line 1. Context lines 2 and 3. CTA last line.
  3 to 5 hashtags maximum. No hashtag stuffing.

- instagram-reel-script.md
  First 2 seconds must hook. 15 to 30 seconds total.
  Write for sound on. Caption for sound off.

- tiktok-script.md
  First 2 seconds must hook or it dies.
  15 to 30 seconds. Speak directly to Brian.
  Energy, humour, local flavour.

- story-caption.md
  One line only. CTA drives to link in bio or swipe up.

## Rules
- Each file opens on a different hook
- Never copy-paste across channels
- CTA matches the channel
- South African voice throughout
- Front-matter on every file: pillar, channel, format, status

## Output contract
- Parent status set to: scheduled
- Log all files created with refactor timestamp
