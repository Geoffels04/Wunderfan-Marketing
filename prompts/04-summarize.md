# Prompt 04: Summarize

Turn one piece of content into one shorter asset.

## Input
Path + target: e.g. 'drafts/[slug].md → caption, 60 words'.

## Output
A single file at drafts/[slug]/[target].md

## Rules
- Same voice. Fewer words.
- One hook. One promise. One CTA.
- No summarizing language like "In this post" or "Here we cover"
- End on a CTA that matches the target channel
- Write for Gareth and Brian simultaneously
- South African references only

## Self-check
- [ ] Reader knows exactly what to do after reading
- [ ] No banned words from CLAUDE.md
- [ ] Hook lands in the first line
- [ ] CTA feels like a benefit not a command
- [ ] Could stand alone without the original content
